这是什么

          
不依赖 Word/WPS/VBA 的 Word 文档批量规范化工具：直接读写 `.docx` 的 OOXML
             （zip + XML，只用 Python 标准库）。

          
用法：选文件 → 左边勾要跑的宏并排序 → 先 dry-run 看会改多少 → 出验证版核对 →
             出正式版交付。正式版跑完会自动体检（AUDIT=PASS）。

          
文件不会被覆盖：结果另存为「某报告（验证版）.docx / （正式版）.docx」。
