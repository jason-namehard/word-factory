应用

应用 = 把「表格模板（名字）」作为一个功能加进执行方案 —— 里面记着每张表用哪款 + 通篇一致勾选；之后跑方案时才真正改文档。 换一份报告时，按表头关键词的映射会自动对上同类表。

数据外置，一句话：把文档里会变的数字搬到 Excel，改完再写回文档

这里**独立导入报告**（跟顶栏的批量清单不相通），可以一份也可以多份。

① 生成外置数据（先在文档里把会变的数值标成高亮）

识别出变量后写一份「XX外置数据.xlsx」（A 项目 / B 数值 / C 段前文字）， 配方追加到生成文档的末尾。你拿到 Excel 里改数值（也可以让计算表跨文件链接它）。

② 更新（Excel 里改完数值后回来点）

文档数据更新：正文里的高亮数值**就地**换成数据表新值（不动段落结构）。
表格数据更新：表格单元格里的高亮数值就地换 —— 表格作为外置数据存储后， 你在 Excel 里把自变量链接进计算表，改完这里一次同步进文档。

这是什么

不依赖 Word/WPS/VBA 的 Word 文档批量规范化工具：直接读写 .docx 的 OOXML （zip + XML，只用 Python 标准库）。

推荐流程：顶栏导入报告（可多份）→「执行方案」页选/调方案（勾功能、排序、 指定前置区）→ 点「运行此方案」出临时版（标蓝，进临时文件夹）→ 满意后点顶栏 「出预览版」核对或直接「出正式版」（自动变黑 + 字体合规 + 体检）。

文件不会被覆盖：结果另存为「某报告（预览版）.docx /（正式版）.docx」。

体检 AUDIT = 重新打开写出的文件、独立复算"通体黑 + 字体合格"，末行 AUDIT=PASS/FAIL —— 正式版跑完自动做，不信工具自己的汇报。
