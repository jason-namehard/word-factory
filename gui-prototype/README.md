# GUI 设计原型（先敲定长相，再接线）

用户 2026-09-23 的要求：「关于 GUI，我希望可以先做 **web 版的拖拽元素**，可以让我把按钮等拽到合适位置，
**按钮链接功能可以晚点做**，需要通过 web 让我敲定一个好看的 GUI」。

所以这里**只有一个自包含的 HTML 文件**：`index.html`

## 怎么用

1. **双击 `index.html`** 用浏览器打开就行 —— 不需要装东西、不需要起服务、不联网也能开
   （字体/CSS/JS 全内联，没引任何外部资源）。
2. 左上角「预设布局」可以先选一个骨架（`左栏 + 主区` / `顶部工具条 + 主区` / `单列向导式`）。
3. 从**左侧组件库**把组件**拖到画布**上；画布内拖动可以移动（自动吸附 10px）。
4. 点中元素 → **右侧可改文字、宽度、高度**；`Delete` 删掉，`Ctrl+Z` 撤销。
5. 想改哪儿就在右侧**备注**里写（比如「运行日志要能折叠」）。
6. 摆好之后点 **「就是它了（存下这版）」**，再点 **「导出布局」** 得到一个
   `wordfactory-gui-layout.json` —— **把这个 JSON（连同备注）发我**，我照它做真界面。

排版会自动存在浏览器里（换页/重启还在），下次打开接着摆。

## 组件库对应的是真功能（不是随便摆的假按钮）

| 组件 | 对应工具箱里的东西 |
|---|---|
| 侧栏 / 标签页 | 各功能入口：宏库、表格款式、段落配方、规则文件、体检 |
| 主工作区 | 当前功能的界面（例如表格款式的模板选择 + 表格清单） |
| **表格清单** | `tablestyle list` 的真实输出：**按表头勾选**哪几张表要套模板（你要的那排复选框） |
| 模板选择器 | 6 个表格模板（外粗内细 / 全居中 / 均布列宽 / 自适应 / 三线表 / 三线表·均布） |
| 预览窗 | 套用后的样子（真做的时候是"先生成一份预览文档让你用 Word 看"） |
| 运行日志 | `--dry-run` 的报告：改了多少处、哪几类 |
| 动作按钮 | 运行（dry-run）/ 出验证版 / 出正式版 / 体检 AUDIT |

## 现在还没做的（**故意**的）

- **按钮不接线**：点了不会真的去改文档 —— 用户要求"按钮链接功能可以晚点做"，
  这一版只解决"**长什么样、元素怎么摆**"。
- 没有多页签切换、没有真实数据（表格清单里的表头是拿你报告的真实表头当样例）。

## 敲定之后我怎么做真界面

两种走法，等用户挑：

1. **本地网页界面**（推荐）：Python 起一个只监听 `127.0.0.1` 的小服务，页面就是这套布局，
   点按钮 = 调对应命令；好处是样式完全可控、跨平台、和 CLI 共用一套代码。
2. **Tkinter 原生窗口**：不用浏览器，但控件样式受限（做到"好看"更难）。

不管走哪条，**布局定稿的 JSON 就是施工图**：元素 → 控件、坐标 → 布局、备注 → 需求清单。

## 另一条路：用 CAD 改（用户擅长 CAD，2026-09-23 提出）

用户原话：「我擅长使用 CAD…你生成一个 CAD 的调整 UI，我来修改（CAD 涉及比例问题，所以你要给我一个
**必须不改大小的框**，然后我在框内修改图标大小，你可以按比例计算）」。

```bash
python dxf_layout.py write 输出.dxf                  # ① 生成模板：画布框 + 初始布局 + 零件库 + 说明
#   用 CAD 打开改（拖矩形、改大小、写字），保存
python dxf_layout.py read 改过的.dxf 布局.json        # ② 读回 → 与网页版**同一种**布局 JSON
```

**约定（也写在 DXF 的说明图层里）**：

* **画布框 = 1440 × 900 图纸单位，1 单位 = 1 像素** —— 就是软件窗口外框，**这个大框不要改大小**；
* 框内每个**矩形 = 一个界面元件**，矩形里写的字就是元件名（我按关键字认类型：
  按钮 / 标签页 / 复选框 / 下拉 / 清单 / 表格清单 / 模板选择器 / 预览窗 / 日志 / 侧栏 / 主工作区…）；
* 框内有 **100 单位一格的参考网格**（图层 GRID，不参与识别）；
* **框外的零件库**（图层 PALETTE）想用哪个就复制进框里；说明在图层 NOTES，我当备注读走；
* 你把整张图缩放也没关系 —— 我按**画布框的实际宽度**等比换算。

技术细节：DXF 是 **R12 ASCII**（兼容性最好，AutoCAD / 中望 / 浩辰 / LibreCAD 都能开），
用 `POLYLINE`+`VERTEX` 画矩形、`TEXT` 写字；读的时候**连 R2000+ 的 `LWPOLYLINE`/`MTEXT` 一起认**
（你在 CAD 里保存通常会变成那种）。中文按 GBK 写（DXF 的代码页规矩），
GBK 编不出来的字符（如 `³`）会自动换成安全写法。
